# SEO HTML Git Lab

Projeto educacional desenvolvido para praticar fundamentos de HTML semântico, CSS básico e versionamento com Git e GitHub, com foco em conceitos aplicáveis ao SEO técnico.

## Objetivos

- Compreender a estrutura de um documento HTML.
- Utilizar elementos HTML semânticos.
- Aplicar estilos básicos com CSS.
- Conhecer o fluxo de versionamento com Git.
- Praticar branches, commits, push, pull requests e merge.
- Identificar elementos básicos de SEO on-page.

## Tecnologias utilizadas

- HTML5
- CSS3
- Git
- GitHub
- Visual Studio Code

## Estrutura do projeto

```text
seo-html-git-projeto-metas/
├── css/
│   └── styles.css
├── images/
├── index.html
└── README.md
```

### Arquivos e pastas

- `index.html`: contém a estrutura e o conteúdo principal da página.
- `css/styles.css`: define a apresentação visual da página.
- `images/`: destinada às imagens do projeto.
- `README.md`: documentação do projeto.

## Conceitos de SEO praticados

- Definição do idioma da página.
- Uso de title e meta description.
- Organização hierárquica dos títulos.
- Utilização de HTML semântico.
- Estruturação de links internos.
- Organização dos arquivos do projeto.

## Como executar

1. Clone o repositório para seu computador.
2. Abra a pasta no Visual Studio Code.
3. Abra o arquivo `index.html` no navegador.
4. Opcionalmente, utilize a extensão Live Server para visualizar as alterações durante o desenvolvimento.

## Versionamento

O projeto utiliza Git para registrar as alterações e GitHub para hospedar o repositório.

O fluxo praticado inclui criação de branch, registro de commits, envio por push, abertura de pull request, revisão e integração à branch principal.
